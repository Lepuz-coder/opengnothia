# Release v1.3.0

## Context
17 commits since v1.2.0. Major new feature: full Courses system with 8 courses, progress tracking, streaming markdown, and a 3-tab course browser. This warrants a minor version bump (v1.3.0).

## Release Notes

```
## v1.3.0 — Courses

### New Features
- **Courses system**: AI-driven interactive courses with step-by-step lessons, progress tracking, and per-course memory
- **8 new courses** (24 steps each, 8 languages): Spiritual Journey, Quit Smoking, Making Peace with Anxiety, Anger Management, Healthy Relationships, Digital Detox, Healthy Eating Psychology, Overcoming Procrastination, Living with Grief and Loss
- **Course browser tabs**: Browse courses by Started, Completed, and Explore tabs with empty-state CTAs
- **Lesson progress bar**: AI-driven real-time progress indicator during lessons
- **Course step descriptions**: Rich localized descriptions for each course step
- **Reset progress**: Ability to reset course progress and start over

### Improvements
- Live markdown rendering during chat streaming
- Improved chat streaming reveal behavior
- Enhanced courses list and journey map UI
- Separated course notes from patient notes for better isolation

### Bug Fixes
- Fixed course lesson lifecycle and progress handling
```
